# 全员 AI 能力提升平台

> 面向企业员工的 **AI 学习、资讯、实践沉淀与运营治理中台**。平台不以展示为目标，而以“学习能力建设、可信资讯、实践复用和责任可追溯”为持续运营闭环。

## 功能总览

| 模块 | 已交付能力 | 运营价值 |
|---|---|---|
| 员工工作台 | 下一步学习、画像、收藏与实践入口 | 让学习、资讯和实践回到日常工作流。 |
| 学习中心 | 路径、课程、进度、资源链接、标签、先修关系 | 将“从 0 到 1 学 AI”拆成可管理的能力路径。 |
| 沉浸式阅读 | PDF 全屏沉浸阅读（连续滚动/单页、键盘翻页、高清渲染）、文档沉浸模式（限宽排版、字号调节）、视频全屏 | 把“看资料”变成“读资料”，减少工具感、提升专注。 |
| 学习互动 | 视频弹幕（轨道化调度）、时间戳评论、PDF 拖选标注（仅本人可见）、断点续播、进度自动保存 | 让学习过程可沉淀、可续接、可交流。 |
| 三类学习资源 | URL 文档采集、PDF/Word/Markdown/图片/视频上传（**流式直传，单个最大 1GB**）、Markdown 阅读、受控模型实操台 | 将单一链接升级为可组合、可追溯的学习资源。 |
| 学习内容台账 | 业务/内容负责人、复审日期、版本、更新说明、资源健康度、资源删除（级联清理） | 保证课程可维护、可追责、可复审。 |
| AI 助手小智 | 全局悬浮球、页面感知（读取当前页面标题/正文/划词）、平台功能指导、文章问答、多轮对话 | 让员工“边用边问”，降低平台上手与内容理解成本。 |
| AI 资讯中心 | RSS 导入、精选全文、时间线、价值排序、聚合阅读与收藏 | 让员工能判断资讯的新旧、价值和企业内关注度。 |
| 实践社区 | 富文本、图片附件、主题关注、引用实践、私有收藏、受控讨论 | 沉淀可复用的企业 AI 经验，而非追逐公开流量。 |
| 审核与治理 | AI 分级直决、人工复核、软删除/恢复、责任链、模型治理 | 将安全、质量和运营责任纳入可审计流程。 |
| 企业应用中心 | 公司 Agent 平台、业务助手和专项工具的登录保护入口；管理员可维护分类、说明、URL、排序与启停 | 让可信工具入口可发现、可运营。 |
| Skills 广场 | 关键词/分类/评分排序、员工投稿、ZIP 安装包、`SKILL.md` 预览、评分评论、受控下载；管理员审核上架/退回/下架、批量直接导入 | 将可复用的 Agent 方法沉淀为可治理的企业资产。 |
| Agent 内容导入 | 可安装内容采集 Skill、最小权限令牌、平台代理图片/附件、结构化草稿、导入批次审核 | 免除复制粘贴与手工传图，但不让外部 Agent 绕过内容治理。 |

## 技术架构

```text
员工端（工作台 / 学习 / 资讯 / 社区 / Workspace / Skills）
                  │
React 19 + Vite + Wouter + TanStack Query + tRPC Client
                  │
Express 4 + tRPC 11（员工保护路由 / 管理员路由 / 审计边界）
        ┌─────────┼─────────┐
        │         │         │
 MySQL/TiDB   Manus OAuth   Manus Forge（LLM / 对象存储）
 Drizzle ORM   角色鉴别       审核、附件签名访问
```

关键安全边界：

- 员工私有画像、Workspace、收藏、阅读关系、PDF 标注与学习进度以当前身份为范围；
- 运营配置、审核记录、删除恢复及内容维护仅允许管理员调用；
- 供应商密钥只保存 **Secret 别名**，不把原始 API Key 写入业务数据库；
- 课程资源上传走**流式直传**（`/api/upload/course-material`），请求体不经内存缓冲直接落盘，单个文件上限 1GB；
- AI 配图与 AI 助手输出在服务端做白名单净化（SVG 剥离脚本/事件/外链），存储后安全内联渲染。

## 快速开始

开发环境需要 Node.js 22+、pnpm 10+ 与 MySQL/TiDB。复制或配置部署环境提供的变量后，在项目根目录运行：

```bash
pnpm install --frozen-lockfile
pnpm drizzle-kit migrate
pnpm test
pnpm check
pnpm dev
```

| 命令 | 用途 |
|---|---|
| `pnpm dev` | 以开发模式启动 Express/Vite 服务（默认 3000，可用 `PORT=3001 pnpm dev` 指定端口）。 |
| `pnpm test` | 运行 Vitest 单元、路由和治理契约测试。 |
| `pnpm check` | 运行 TypeScript 类型检查。 |
| `pnpm build` | 构建前端和 Node 服务端产物至 `dist/`。 |
| `pnpm start` | 以生产模式启动构建产物。 |
| `pnpm drizzle-kit generate` | 依据 schema 生成待审阅的迁移。 |
| `pnpm drizzle-kit migrate` | 应用已提交且经审阅的迁移。 |

> **注意：** 不要使用 `pnpm db:push` 作为生产数据库的默认迁移方式；它会先生成再直接迁移，缺少人工审阅关卡。

## 核心功能

### 学习中心（沉浸式阅读）

学习中心按“路径 → 课程 → 素材”组织，进度自动累计：

- **学习中心首页**：等高卡片网格、学习统计（连续天数/本周分钟/已完成节数）、继续学习横幅、分类筛选与搜索；
- **PDF 阅读器**：全屏沉浸模式（快捷键 `F`）、fit-width 自适应缩放、单页/连续滚动双模式、键盘翻页（`←`/`→`）、页码跳转、高分屏高清渲染、工具栏自动隐藏；
- **PDF 标注**：开启“标注”后在页面上拖选区域，支持 5 种颜色与笔记，仅本人可见，可跳页/删除；
- **文档阅读器**：沉浸模式 + 限宽排版（42rem 舒适行长）+ 字号三档调节，滚动深度自动记进度；
- **视频播放器**：倍速（0.75×–2×）、快捷键（空格/`J`/`L`/`F`）、全屏、轨道化弹幕层、进度条时间戳标记、断点续播；
- **进度自动保存**：视频每 20 秒自动保存播放位置，暂停/切走/关闭页面时补存；PDF 翻页、文档滚动即时记录；全部素材完成后自动结课；
- **学习分钟数**：按“距上次上报的增量”累计（视频按累计播放秒，PDF/文档按页面停留秒），避免重复累计。

### AI 助手小智

全局右下角悬浮球，登录后所有页面可用：

- **页面感知**：自动读取当前页面类型、标题与正文摘录（资讯全文、课程素材、帖子+评论、Skill 描述、个人画像等），随提问注入模型；
- **划词问答**：选中页面文字后可直接让助手解释、翻译、改写；
- **平台指导**：内置平台功能知识库，回答“怎么发弹幕 / PDF 怎么标注 / 在哪里上传视频”等操作问题；
- **多轮对话**：携带最近 16 条历史，Markdown 渲染，跨路由保留；
- 每人每天 60 次问答，问答记录仅本人与授权运营可见。

### AI 资讯中心

- RSS 导入、精选全文、时间线（今日/近 7 天/近期/历史）、价值排序、聚合阅读与收藏；
- 阅读计数是员工与资讯的唯一关系聚合，平台不展示阅读者身份。

### 实践社区

- 富文本、图片附件、主题关注、引用实践、私有收藏、受控讨论（可限制仅运营评论）。

### Skills 广场

- 员工投稿（`SKILL.md` + ZIP 安装包）、评分评论、受控下载与复制安装指令；
- 管理员审核上架/退回/下架，支持批量直接导入（最多 10 个/批）。

### 审核与治理

- AI 审核仅在低/中风险且达到阈值时直接通过或拒绝；高风险、关键风险和低置信一律人工复核；
- 删除采用软删除并强制填写原因，操作人/时间/原因进入审核记录；恢复后回到人工复核。

## 运营使用说明

### 学习内容如何维护

管理员进入 **运营管理 → 学习内容运营**（学习中心/路径详情/课程页均有管理员直达入口）。先建立草稿学习路径，再配置路径中的课程、资源、标签、先修关系和顺序；补齐业务负责人、内容负责人、复审日期、版本号与更新说明后发布。员工端仅读取已发布课程。

**课程资源管理**支持三类资源：

| 类型 | 维护方式 | 员工端体验 |
|---|---|---|
| 文档型 | 采集公开 URL，或上传 PDF/Word/Markdown/文本/图片 | 沉浸阅读、PDF 拖选标注、滚动记进度 |
| 视频型 | 上传 MP4/WebM（**流式直传，单个最大 1GB**）或填外部视频 URL | 弹幕、倍速、时间戳评论、断点续播、全屏 |
| 实操型 | 配置固定教学指令 | 受控模型实操台（每日 5 次，结果仅本人可见） |

资源卡片支持**维护**与**删除**；删除会级联清理该资源的评论、标注、进度与实操历史，操作前有确认弹窗。

### AI 资讯如何维护

管理员在 **运营管理** 添加或编辑 RSS 来源并“同步”拉取。导入条目进入待审核队列，可由批量 AI 预审过滤高置信低质量内容；高风险、低置信或失败条目保留给人工处理。

### 审核模型与应用中心如何维护

管理员在 **运营管理 → AI 审核员 → 配置** 选择供应商和已启用模型后点击“测试连接”。外部供应商若仅登记 Base URL 与密钥别名，会被明确提示“尚未完成受管网关接入”，可保留配置但不能启用为实际审核员。

管理员在 **运营管理 → 管理应用入口** 维护企业应用入口（名称、说明、URL、分类、可见范围、排序与启停）。应用中心不保存第三方账号或密钥。

### Skills 广场如何分享和审核

员工从 **Skills 广场 → 分享 Skills** 提交；投稿先处于待审核状态。管理员在 **运营管理 → 治理 Skills 投稿** 审阅详情后上架、退回或下架。详情页向已授权访问者提供受控下载和可复制的自然语言安装指令；下载链接为短期签名 URL。

## 贡献与变更规范

任何功能变更应遵循以下顺序：更新 `drizzle/schema.ts`（如涉及数据）→ 生成并审阅迁移 → 应用迁移 → 修改服务端与前端 → 补充 Vitest 测试 → 运行 `pnpm test && pnpm check`。涉及发布内容、审核、权限、删除、员工个人数据或外部来源时，优先选择可恢复、可审计、最小权限的设计。
