# ADR-0001：学习内容采用安全 HTML 快照

## 状态
accepted

学习中心对公开 HTML 与 GitBook 页面保存服务端清洗后的 HTML 快照，前端只展示快照并保留“打开原站”入口；不默认嵌入任意第三方页面。这样在保留标题、列表、代码、表格等排版的同时，避免第三方脚本、登录态、CSP 与跨域行为让学习页变得不可控。长 PDF 则默认单页并按需渲染，避免课程页一次性初始化大量 canvas。

## 被拒绝的方案

- 任意 iframe：交互更完整，但依赖第三方允许嵌入，且会引入登录态、脚本和跨域安全边界。
- 只保存纯文本：安全简单，但会丢失文档结构和学习所需的代码、表格、层级信息。
